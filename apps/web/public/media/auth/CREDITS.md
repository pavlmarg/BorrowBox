# Auth page videos

The source clips are from Pexels, under the [Pexels licence](https://www.pexels.com/license/): free for commercial use, no attribution required. They were re-encoded for the web with ffmpeg: cropped, scaled, audio removed, H.264 at CRF 27, and the last 0.8 s crossfaded into the start so each video loops without a visible jump.

| File | Source clip | Used on |
|---|---|---|
| `register-wide.mp4` / `.jpg`, `register-tall.mp4` / `.jpg` | Pexels video 13441295 (2160×3840, 24 fps) | Register (video on the right; full screen on phones) |
| `login-wide.mp4` / `.jpg`, `login-tall.mp4` / `.jpg` | Pexels video 7844377 (3840×2160, 25 fps) | Login (video on the left; full screen on phones) |

`-wide` is used from 960 px up and `-tall` below that. Each `.jpg` is the first frame, shown as the poster while the video loads and as a still image under reduced motion.
